# Original image-generation assets

All four assets were generated with the built-in image generation tool, using subscription tooling rather than a separately configured image API. Original generated files remain preserved; the game consumes optimized WebP copies.

1. **Concept — `concept.png`.** Full desktop game home screen, original RELIC RIOT branding, ivory condensed italic title and warm amber actions. Live form anatomy: callsign, four runner choices, create, join, practice. Floating ancient temple in violet clouds with an amber relic, violet obelisks, sandstone walkways and masked thieves. All requested text and controls were specified in the image brief. This image is a design reference, not the application UI.
2. **Temple — `../public/art/temple.webp`.** Edit the concept into a standalone environment asset. Remove all text, UI, characters and logos. Preserve the right-hand floating temple and relic, with dark violet negative space on the left for live interface text.
3. **Runner portraits — `../public/art/runners.webp`.** Four evenly spaced, original low-poly hooded thief portrait busts. Ivory masks, dark eyes, amber rim light. Turquoise, orange, violet and lime cloak variants. No text, scenery or frames. The atlas supplies selectable portraits; live playable characters are original animated Three.js meshes.
4. **Cloudscape — `../public/art/sky.webp`.** Standalone dark aubergine night sky, sparse stars, layered violet clouds at the bottom and sides, tiny distant floating silhouettes and amber motes. Leave the center open for the actual 3D arena. No temple, floor, characters, text or UI.

The detailed composition, exact interface copy, colors and implementation decisions are recorded in `../DESIGN.md`. Compression changes file format and size; it does not replace or redraw the generated artwork.
